# Navy Captação

Formulário responsivo com nome, CNPJ, e-mail e produto de interesse.

Abre uma mensagem para +55 11 94855-7398. O cliente confirma o envio no WhatsApp. O formulário não armazena dados e não envia mensagens automaticamente.

## Publicação

Em Settings > Pages, selecione Deploy from a branch, branch main, pasta / (root) e Save.

## Personalização

Edite index.html para alterar textos, cores e campos.
